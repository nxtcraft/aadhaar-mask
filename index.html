Frequently Asked Questions

Is my Aadhaar data safe?

Completely. This tool runs entirely in your browser using JavaScript. Your document is never sent to any server. Once you close the tab, nothing is retained.

What is Aadhaar masking?

UIDAI (the Aadhaar authority) recommends masking/hiding the first 8 digits of the 12-digit Aadhaar number when sharing for KYC or verification — only the last 4 digits should be visible. This reduces misuse risk while still confirming identity.

Can I use this for passports, PAN cards or other documents?

Yes. This tool works on any image or PDF. You can redact any sensitive field — bank account numbers, phone numbers, addresses — by drawing mask boxes over them.

Does it work on PDFs?

Yes. Multi-page PDFs are fully supported. Navigate between pages using the arrows, apply masks to each page, and download as a single PDF.
